# CodeAlpha Task 1 - Iris Flower Classification

## Project Overview

This project is part of the CodeAlpha Internship Task 1.

The objective is to build a machine learning classification model that identifies Iris flower species based on flower measurements.

## Dataset

The Iris dataset contains three flower species:

- Setosa
- Versicolor
- Virginica

The features used are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Model

Logistic Regression is used for classification.

## Steps Performed

1. Loaded the Iris dataset
2. Explored the dataset
3. Checked missing values
4. Split the data into training and testing sets
5. Standardized the features
6. Trained the Logistic Regression model
7. Made predictions
8. Evaluated model accuracy
9. Generated a classification report
10. Generated a confusion matrix
11. Saved the trained model

## Project Files

- `01_load_iris_dataset.py` - Loads and explores the dataset
- `02_iris_classification.py` - Trains and evaluates the ML model
- `requirements.txt` - Required Python libraries
- `iris_dataset.csv` - Dataset
- `iris_model.pkl` - Trained model
- `iris_scaler.pkl` - Feature scaler
- `confusion_matrix.png` - Model evaluation visualization
- `iris_results.txt` - Model results

## Result

The model successfully classifies Iris flower species using their measurements.
